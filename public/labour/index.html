Using the labour sheet

Every change is written straight into the Labour workbook in SharePoint — the Excel file is the master. Changes made by anyone, here or in Excel, appear on everyone's screen within a few seconds (cells changed by someone else flash orange).

Click / dragSelect cells (Shift+click extends)
Type, Enter or double-clickEdit — the value goes into every selected cell
DeleteClear the selected cells
Ctrl+C / Ctrl+VCopy and paste (also to and from Excel)
Ctrl+ZUndo your last change
ArrowsMove (Shift extends)
T / D / RToday · day view · reload
PhoneTap a cell to select it, tap again to edit

Inserting or deleting rows, colours and formulas are still done in Excel; the app picks them up automatically.
